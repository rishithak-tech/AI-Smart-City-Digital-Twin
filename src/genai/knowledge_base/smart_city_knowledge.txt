SMART CITY DIGITAL TWIN KNOWLEDGE BASE

PROJECT OVERVIEW

The Smart City Digital Twin is an AI-based decision-support prototype
designed for Hyderabad urban scenarios.

The system integrates environmental data, weather information,
computer vision, machine learning, deep learning, and reinforcement
learning into a unified digital-twin architecture.

The system is designed to:
1. Monitor a simulated representation of city conditions.
2. Forecast near-term air quality.
3. Analyze traffic scenes using computer vision.
4. Estimate a scene-level traffic density indicator.
5. Simulate possible traffic-management interventions.
6. Select an intervention using reinforcement learning.
7. Explain the resulting decision in human-readable language.


AIR QUALITY FORECASTING

Historical Hyderabad air-quality observations are used to forecast
the AQI for the next hour.

The project evaluates:
- Random Forest
- XGBoost
- XGBoost with weather features
- LSTM deep-learning model

The strongest forecasting model in the current experiments is
XGBoost with weather features.

Current evaluation results:

MAE: 18.97
RMSE: 25.41
R-squared: 0.6308

The model uses historical AQI patterns together with weather-related
features such as temperature, humidity, wind speed, wind direction,
and surface pressure.

The forecast represents a machine-learning prediction and should
not be interpreted as a guaranteed future AQI value.


COMPUTER VISION

The project uses the IDD Lite dataset for urban road-scene
understanding.

A lightweight U-Net semantic segmentation model is trained to
identify seven Level-1 scene classes.

The classes are:

0 - Drivable
1 - Non-drivable
2 - Living-thing
3 - Vehicles
4 - Road-side objects
5 - Construction
6 - Sky

255 represents ignored or void pixels.

Current U-Net evaluation:

Pixel Accuracy: 0.8279
Mean IoU: 0.5210
Vehicle IoU: 0.5536

The computer-vision module provides scene-level information and
does not represent a real-time traffic sensor.


TRAFFIC DENSITY

Traffic-related features are extracted from semantic segmentation
masks.

Important features include:

- Vehicle pixel ratio
- Living-thing pixel ratio
- Drivable pixel ratio
- Construction pixel ratio
- Sky pixel ratio

A project-defined traffic density indicator is derived from these
scene features.

This traffic density indicator is an engineered simulation input.
It is not a validated measurement of real-world traffic volume.


DIGITAL TWIN

The Digital Twin combines multiple information sources into a
unified city state.

The city state contains:

- Current AQI
- Predicted next-hour AQI
- Temperature
- Humidity
- Wind speed
- Wind direction
- Surface pressure
- Traffic density indicator
- Traffic risk
- Air-quality risk

The Digital Twin allows the system to evaluate hypothetical
changes in city conditions.


WHAT-IF SIMULATION

The What-If Simulator evaluates hypothetical traffic-management
interventions.

The current intervention actions are:

0% traffic change
-10% traffic reduction
-20% traffic reduction
-30% traffic reduction
-40% traffic reduction

For each scenario, the system evaluates:

- New simulated traffic density
- Traffic benefit
- Environmental improvement indicator
- Intervention cost
- Simulation reward

These values are generated by the project's simulation model.


REINFORCEMENT LEARNING

The project uses a Deep Q-Network (DQN) to select traffic-management
actions.

The DQN observes:

- AQI
- Traffic density
- Temperature
- Humidity
- Wind speed

Available actions:

0%
-10%
-20%
-30%
-40%

The DQN estimates a Q-value for each possible action.

The action with the highest Q-value is selected as the recommended
intervention.

A Q-value represents the estimated long-term value of an action
under the learned simulation policy.

The DQN was trained inside the project's simulated environment.
Therefore, its recommendation should be interpreted as a policy
decision within the simulation rather than a guaranteed real-world
optimal intervention.


ENVIRONMENTAL IMPACT

The project contains a simulation-based environmental pressure
indicator.

The indicator considers:

- AQI
- Traffic density
- Humidity
- Wind speed

It is used to compare hypothetical scenarios.

The environmental improvement value is a simulation indicator.

It is NOT a scientifically validated causal prediction of how much
real-world AQI will change after reducing traffic.

DATA LIMITATIONS

The air-quality dataset and weather dataset provide historical
information rather than live city measurements.

The IDD Lite traffic scenes are not timestamp-aligned with the
Hyderabad AQI observations.

Therefore, the current system should be described as an integrated
prototype and simulation-based Digital Twin rather than a
real-time city monitoring system.

Traffic scene information and environmental observations should
not be assumed to represent the exact same physical moment.


AI EXPLANATION

The GenAI layer is intended to retrieve relevant information from
this knowledge base and use it to explain:

- Why an intervention was selected
- What the intervention changes
- How alternative scenarios compare
- What the model inputs mean
- What limitations apply to the recommendation

The AI explanation should distinguish clearly between:

1. Observed historical data
2. Machine-learning predictions
3. Computer-vision estimates
4. Simulation outputs
5. Reinforcement-learning recommendations

The system should never present a simulation result as a measured
real-world fact.
